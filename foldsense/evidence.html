Why did you say that?

FoldSense keeps molecular measurements, external retrieval and model-generated language as different evidence classes. Hashing records custody; signing is only claimed after an authorized project key actually signs the canonical record.

Dependency path

source state→frame→deterministic metric→event→renderer/model response

External web/research evidence branches separately: source URL → retrieval record → synthesis.

Current public claim boundary

  • Hash-linked provenance: supported when hashes are actually computed.
  • Digital signature: only when authorized project key is available.
  • Merkle commitment: not implied by ordinary SHA-256 records.
  • Independent verification: separate operation.
